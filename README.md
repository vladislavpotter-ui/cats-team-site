# Cats Team — GitHub-ready static site

Это статическая версия сайта Cats Team в фирменных цветах логотипа.

## Что внутри
- index.html — главная
- services.html — услуги
- cases.html — кейсы
- about.html — о нас
- contacts.html — контакты
- css/styles.css — стили
- js/site.js — мобильное меню
- assets/cats-team-logo.png — логотип

## Где хранить бесплатно
1. **GitHub Pages** — бесплатно, удобно для статического сайта.
2. **Cloudflare Pages** — бесплатно, быстро, удобно подключать домен.
3. **Netlify** — бесплатный тариф для статических сайтов.
4. **Vercel** — тоже подойдёт для статических сайтов.

## Как редактировать бесплатно
- редактировать прямо в GitHub через веб-интерфейс;
- редактировать локально в VS Code и отправлять изменения в GitHub;
- использовать GitHub Desktop, если нужен более простой интерфейс.
