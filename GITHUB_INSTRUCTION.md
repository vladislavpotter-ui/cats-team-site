# Инструкция: как перенести Cats Team на GitHub

## Вариант 1 — через сайт GitHub
1. Создайте аккаунт на https://github.com/
2. Нажмите **New repository**.
3. Назовите репозиторий, например `cats-team-site`.
4. Сделайте его Public, если хотите бесплатный GitHub Pages без ограничений.
5. Создайте репозиторий.
6. Загрузите содержимое этого архива в корень репозитория через **Upload files**.
7. После загрузки откройте **Settings → Pages**.
8. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
9. Сохраните настройки.
10. Через 1–3 минуты сайт появится по адресу вида:
   `https://ВАШ-ЛОГИН.github.io/cats-team-site/`

## Вариант 2 — через GitHub Desktop
1. Установите GitHub Desktop.
2. Создайте репозиторий.
3. Распакуйте архив сайта в папку репозитория.
4. Сделайте первый commit.
5. Нажмите **Publish repository**.
6. Включите GitHub Pages в настройках репозитория.

## Как редактировать сайт потом
- откройте нужный `.html` файл прямо в GitHub и нажмите значок карандаша;
- внесите изменения;
- нажмите **Commit changes**.

## Как заменить домен позже
Если будет свой домен, его можно подключить:
- к GitHub Pages,
- к Cloudflare Pages,
- к Netlify,
- к Vercel.
